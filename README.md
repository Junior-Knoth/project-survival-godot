# Project Survival

A 2D top-down survival game focused on interconnected systems, progression and player-driven development.

The project is currently in an early prototype stage and is being developed with Godot.

## Current Features

- Player movement and directional sprites
- Basic interaction system
- Interactable world objects
- Early resource harvesting prototype

## Planned Features

- Procedural world generation
- Items, tools and inventory
- Crafting and resource gathering
- Building system
- Farming and survival mechanics
- Electrical and hydraulic systems
- Technological progression
- NPCs and settlement development

## Engine

- Godot 4
- GDScript

## Status

Early development / prototype.
